# Coforge Technical Training

A structured record of hands-on work completed during Coforge training across **Java full-stack development, software testing, microservices, and data engineering**.

## Learning areas

- Core Java, object-oriented programming, collections, exceptions, and JDBC
- Spring Boot, Spring MVC, REST APIs, Hibernate/JPA, and Maven
- MySQL database design and persistence
- Microservices fundamentals and service-oriented application design
- Manual, UI, API, performance, and database testing
- Data engineering exercises and assessments

## Repository structure

The folders are organised chronologically by training day and assessment. Each directory contains the source code or exercises completed for that module.

## Capstone work

The training culminated in a full-stack flight reservation system with role-based customer/admin flows, flight search and booking, wallet operations, booking management, MySQL persistence, and PDF ticket generation.

## Purpose

This repository is maintained as a learning archive and evidence of practical industry training. Individual folders may require their own IDE, database, or environment configuration.

> Training repository — not a single production-deployable application.
